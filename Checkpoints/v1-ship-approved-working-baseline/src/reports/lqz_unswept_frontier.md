## UNSWEPT — named so it is not mistaken for covered
1. **THE FOUR CALIBRATION INPUTS' SENSITIVITY.** `lqzTol · lqzMinAgree · lqzWickMult ·
   lqzReject` are "OPEN calibration owner=operator" and two are documented as *PROPOSED, not
   measured*. The sweep is running; until it lands, no value's effect is quantified.
2. **THE EMITTER'S FILL PATH.** `lqzFill3` / `lqzFillA` gate the zone rectangles — the exact
   layer the library has and the deliverables lack. Never swept; only the code was read.
3. **THE V2 DETECTOR'S INTERNAL KNOBS.** `lqzSwingLen` (pivot length), `lqzRejectWin`
   (rejection window), `lqzMaxZones`, `lqzMaxLevels` — four more inputs with no sensitivity
   data.
4. **PER-PANEL A/B.** The cross-reference ran on the COMPOSED grids. The per-panel captures
   beneath them were overwritten per TF and were never measured individually.
5. **THE TRANSITIONS.** The pin's H4 lists "switch TF mid-render" and "toggle lqzSource" as
   pushes. Both were exercised only implicitly (a fresh load per TF); neither was driven
   MID-RENDER on a live page.
6. **THE NATIVE WIDGETS.** The timeframe selector and the settings dialog were never operated
   — every load went through the page's own `loadBars`/`setSource` API rather than the UI
   controls a human would click.
7. **THE OTHER 3 SHIP DESKS' OUTPUTS AT THE INPUT LEVEL.** D1 and D3 were verified by title +
   counts + look; only D2 was source-asserted for its detector's default (`lqzSource =
   "candles"`).
8. **THE STATION'S HALF-ALIVE STATE.** Fixed blindness in the launcher; the state itself is
   intermittent and unreproduced.

## THE HONEST POSITION
Items 1-3 are INPUT-SENSITIVITY questions and belong to the operator's calibration (the pin
assigns them to the operator explicitly). Items 4-8 are genuine coverage gaps: each could
hide a defect, and none is claimed as verified.
